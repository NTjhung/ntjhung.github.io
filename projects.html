1. Entra ID User Lifecycle Automation

Built a Microsoft Entra ID user lifecycle automation lab using PowerShell and Microsoft Graph to simulate onboarding, group assignment, access removal, and audit evidence collection.

Microsoft Entra ID PowerShell Microsoft Graph User Lifecycle Audit Evidence

Problem

Organizations need a consistent way to onboard, update, and offboard users while reducing manual errors and preventing unnecessary access.

2. Conditional Access Security Baseline

Designed and configured Microsoft Entra Conditional Access policies in report-only mode, including administrator MFA, pilot user MFA, legacy authentication blocking, sensitive group protection, break-glass account exclusions, testing strategy, rollback planning, and audit evidence documentation.

Conditional Access MFA Report-Only Mode Break-Glass Planning Rollback Planning

Problem

Organizations need to protect user identities without accidentally locking out users or administrators. Conditional Access policies improve security, but they must be planned, tested, and documented carefully.

What I Built

  • Created a Conditional Access pilot group.
  • Added selected test users to the pilot group.
  • Documented a break-glass account for emergency access planning.
  • Created live Conditional Access policies in report-only mode.
  • Created an administrator MFA policy.
  • Created a pilot user MFA policy.
  • Created a legacy authentication blocking policy.
  • Created a sensitive groups MFA policy.
  • Created rollback documentation and testing notes.
