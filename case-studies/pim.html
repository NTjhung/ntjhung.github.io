Project Summary

This project demonstrates Microsoft Entra Privileged Identity Management for privileged access control. The lab focuses on reducing standing administrator access by using eligible role assignments, just-in-time activation, justification, time-limited access, break-glass planning, and audit evidence.

Business Problem

Organizations need to reduce the risk of excessive or unnecessary administrator access. Permanent admin access can create security risk if an account is compromised or misused. Privileged Identity Management helps reduce standing access by allowing users to activate privileged roles only when needed.

What I Built

  • Opened and configured Microsoft Entra Privileged Identity Management.
  • Selected a safer privileged role for lab testing.
  • Assigned a role as eligible instead of permanently active.
  • Reviewed role settings.
  • Activated an eligible role as a test user.
  • Entered a business justification for activation.
  • Confirmed the role became active temporarily.
  • Captured PIM audit evidence.
  • Documented break-glass planning.

Documentation Summary

Eligible Access

Eligible access means the user can activate the role when needed, but the role is not active all the time.

Just-in-Time Access

Just-in-time access allows privileged access to be activated only for a limited period.

Justification

Justification requires the user to document why privileged access is needed before activating the role.

Break-Glass Planning

Break-glass accounts provide emergency access if normal administrator access is unavailable. They should not be used for daily administration.

Testing Approach

  1. Open Microsoft Entra Privileged Identity Management.
  2. Select a safer administrator role for testing.
  3. Assign the role as eligible.
  4. Review role settings.
  5. Sign in as the PIM test user.
  6. Activate the eligible role.
  7. Enter business justification.
  8. Confirm temporary active access.
  9. Capture audit evidence.
